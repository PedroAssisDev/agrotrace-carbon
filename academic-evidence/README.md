# Academic evidence (histórico)

Artefatos e scripts históricos separados do software executável.

O runtime, os testes atuais e a documentação canônica **não** dependem deste diretório.

Conteúdo típico:

- auditorias e relatórios históricos;
- scripts one-shot de migração/correção já concluídos;
- evidências Sepolia / manifests históricos;
- capturas e logs sanitizados.

Pacote irmão: `software-release/` (export limpo gerado por `tooling/build_software_release.py`).
